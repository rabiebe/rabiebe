## About me

I build and maintain .NET applications in production: **ASP.NET Core**, **Entity Framework Core**, **SQL Server**, **Angular**.

I currently work as a freelance Full Stack Developer for **CEGEDIM** (Rabat), maintaining both new and legacy applications, working with SQL Server and MongoDB, and applying engineering practices: unit testing, code reviews, design documentation.

Before that, I worked on e-commerce features (2024–2025), management applications at **OMNIYAT** (2022–2024) — inventory, transport, EDI data synchronization — and a cash management application with an SSO module at **Value IT** (2020–2021).

On the architecture side, I structure my personal projects with **Clean Architecture** and **CQRS**. To compare approaches objectively, I built the same domain twice: classic N-Tier and Clean Architecture + CQRS — same business rules, same endpoints.
